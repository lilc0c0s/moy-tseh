# Результаты пилотной эксплуатации

## Площадки

Апробация на трёх действующих мебельных предприятиях Пензенской области:
- **ООО «Экомебель»** — основная пилотная площадка (промышленная эксплуатация);
- ещё два производства (внедрение).

Основной хронометраж — выборка из **30 мастеров сборочного цеха** ООО «Экомебель».

## Метрики

| Показатель | До внедрения | После | Методика |
|---|---|---|---|
| Время фиксации производственной спецификации | 5,0 мин | **30 сек** | хронометраж операций мастеров |
| Точность складского учёта | 67% | **94%** | сверка учётных остатков с инвентаризацией |
| NL → корректный SQL | — | **92,4%** | корпус 500 реплик с производственным сленгом |
| Галлюцинации в финансовых ответах | — | **0 / 1 200** | ручная проверка всех финансовых запросов пилота |

## Интерпретация

- Десятикратное ускорение фиксации операций — главный фактор вовлечения линейного персонала: учёт перестал быть «отдельной работой после смены».
- Рост точности склада с 67% до 94% — прямое следствие: операции фиксируются в момент выполнения, а не по памяти.
- Экономика для предприятия: сокращение потерь от расхождений склада и ускорение подготовки производственных заданий.
